Clipper Uploader: Privacy Policy

Last updated: 2026-10-21

Clipper Uploader is a private tool used only by its owner to upload videos to the owner's own YouTube channel. It uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

What data is accessed

The tool requests only the youtube.upload permission to upload videos to the authorizing account's channel. It does not read, collect, store or share any other YouTube or Google account data.

Storage

The OAuth access token is stored only on the owner's computer, readable only by the owner. No data is sent to any server other than Google's APIs.

Revoking access

Access can be revoked at any time at Google security settings.
